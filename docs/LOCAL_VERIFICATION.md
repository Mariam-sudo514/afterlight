# Проверка локального AFTERLIGHT

Дата: 16–18 сентября 2026. Рабочая папка: `/Users/maria/Desktop/afterlight`.

## Результат

Запущен настоящий Next.js App Router с PostgreSQL, Supabase Auth и private Storage в Docker. Основной журнал отвечает на `http://127.0.0.1:3300/ru` и `/en`. Вход — `/login?lang=ru`, редактор — `/admin?lang=ru`.

Основная база содержит три исходных стартовых материала. Настоящая база прежнего размещённого сайта в эту копию не входила. Старый хостинг не подключался. Существующая мобильная адаптация редактора и архивные метки сохранены.

В начале проверено состояние каталога: `.git` отсутствует, поэтому git status/коммиты недоступны. Перед изменениями создан архив текущих исходников `work/backups/before-next-migration.tar.gz`. Исходная версия из внешнего архива не подставлялась.

## Что нужно сделать владельцу

Один раз в обычном интерактивном терминале:

```bash
cd /Users/maria/Desktop/afterlight
pnpm local:owner
```

Введите email, имя и пароль. Пароль вводится без отображения и не записывается в репозиторий. В основной базе владелец намеренно ещё не назначен: личный пароль выбирает пользователь. Готовность механизма входа и редактора подтверждена отдельными техническими аккаунтами; вход с вашим будущим аккаунтом ещё не выполнялся.

Повторный запуск:

```bash
cd /Users/maria/Desktop/afterlight
pnpm local:start
pnpm dev
```

Состояние — `pnpm local:status`; остановка приложения — Ctrl+C; остановка основных сервисов — `pnpm local:stop`; перезапуск с сохранением volumes — `pnpm local:restart`.
